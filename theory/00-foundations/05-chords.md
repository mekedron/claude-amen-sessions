# Chords

A chord is a set of pitches sounded together. Written here as **semitone offsets
from the root**, so `[0, 4, 7]` + root 60 = C major = MIDI `[60, 64, 67]`.

## Triads

| Name | Symbol | Offsets | Sound |
|---|---|---|---|
| Major | `C` | `[0, 4, 7]` | Bright, stable |
| Minor | `Cm` | `[0, 3, 7]` | Dark, stable |
| Diminished | `Cdim`, `C°` | `[0, 3, 6]` | Tense, unstable, wants to move |
| Augmented | `Caug`, `C+` | `[0, 4, 8]` | Suspended in air, symmetric, uncanny |
| Suspended 4th | `Csus4` | `[0, 5, 7]` | Open, unresolved, heroic |
| Suspended 2nd | `Csus2` | `[0, 2, 7]` | Open, airy, modern, neutral gender |
| Power chord | `C5` | `[0, 7]` | No third → neither major nor minor |

The **third** decides major vs minor. Remove it (sus, power) and the chord
becomes modally ambiguous — which is why sus2 and power chords are everywhere in
electronic music: they fit over anything.

## Seventh chords

| Name | Symbol | Offsets | Function / feel |
|---|---|---|---|
| Major 7 | `Cmaj7`, `CΔ7` | `[0, 4, 7, 11]` | Dreamy, lush, at rest. Lo-fi, neo-soul, bossa. |
| Dominant 7 | `C7` | `[0, 4, 7, 10]` | Tension; contains a tritone; wants to resolve down a 5th. Blues, funk. |
| Minor 7 | `Cm7` | `[0, 3, 7, 10]` | Soft, groovy, at rest in minor. House, jazz, R&B. |
| Half-diminished | `Cm7b5`, `Cø7` | `[0, 3, 6, 10]` | The ii of a minor key. Melancholy, jazzy. |
| Diminished 7 | `Cdim7`, `C°7` | `[0, 3, 6, 9]` | Fully symmetric; maximum instability; pivots anywhere. |
| Minor-major 7 | `CmMaj7` | `[0, 3, 7, 11]` | Sinister, James Bond, hitchcockian. |
| Augmented 7 | `C7#5` | `[0, 4, 8, 10]` | Dominant with a lift; jazz, psychedelia. |
| 6th | `C6` | `[0, 4, 7, 9]` | Vintage, sweet, final. 1950s, city pop, exotica. |
| Minor 6th | `Cm6` | `[0, 3, 7, 9]` | Dorian colour, noir, tango. |
| 7sus4 | `C7sus4` | `[0, 5, 7, 10]` | Deferred dominant. House, gospel, modal jazz. |

**Seventh chords are the default in every groove-based genre.** Plain triads
read as folk, rock, punk, trance anthem or classical. If a house or R&B chord
sounds "amateur", it is almost always because it is a bare triad.

## Extensions: 9, 11, 13

Keep stacking thirds past the 7th. The extension numbers are compound intervals:
9 = 14 semitones (a 2nd + octave), 11 = 17, 13 = 21.

| Chord | Offsets | Notes |
|---|---|---|
| `Cadd9` | `[0, 4, 7, 14]` | Major triad + 9, **no 7th**. Pop's favourite chord. |
| `Cm(add9)` | `[0, 3, 7, 14]` | Minor + 9. Beautiful, everywhere in modern pop and EDM. |
| `Cmaj9` | `[0, 4, 7, 11, 14]` | Lush, floating. |
| `Cm9` | `[0, 3, 7, 10, 14]` | The single most useful chord in house, R&B, liquid D&B. |
| `C9` | `[0, 4, 7, 10, 14]` | Funk. James Brown. |
| `C11` (dominant) | `[0, 7, 10, 14, 17]` | Usually drop the 3rd (it clashes with the 11). |
| `Cm11` | `[0, 3, 7, 10, 14, 17]` | Wide, modal, "no colour" — great pads. |
| `C13` | `[0, 4, 10, 14, 21]` | Drop the 5th and 11. Big-band, funk, disco. |
| `Cmaj7#11` | `[0, 4, 7, 11, 18]` | Lydian sky. Film, dream pop, EDM pads. |
| `Cm6/9` | `[0, 3, 7, 9, 14]` | Cool, Steely Dan, city pop. |

**Rule of extensions:** an extension is only "correct" if it belongs to the
scale of the moment, with one exception — the **11 over a major or dominant
chord clashes with the major 3rd** (a b9 apart). Either sharpen it (#11) or
drop the 3rd (sus/11 chord).

## Altered dominants

On a dominant chord, any of 5 and 9 may be raised or lowered. These are the
tension chemicals.

| Chord | Offsets | Character |
|---|---|---|
| `C7b9` | `[0, 4, 7, 10, 13]` | Dark, classic, resolves hard to minor |
| `C7#9` | `[0, 4, 7, 10, 15]` | The "Hendrix chord"; major and minor at once |
| `C7b5` | `[0, 4, 6, 10]` | Whole-tone flavour |
| `C7#5` | `[0, 4, 8, 10]` | Lifting, unstable |
| `C7alt` | `[0, 4, 10, 13, 15, 18, 20]` (pick 4–5) | Maximum tension; use altered scale |
| `C13b9` | `[0, 4, 10, 13, 21]` | Big-band bite |

Rule of thumb: **alterations belong on the chord immediately before a
resolution**, and almost nowhere else. Altering a chord that is not going
anywhere just sounds wrong.

## Quartal, cluster and modern voicings

| Type | Construction | Sound |
|---|---|---|
| **Quartal** | stack 5s: `[0, 5, 10, 15]` | Modal, ambiguous, McCoy Tyner, sci-fi, ambient |
| **So What voicing** | `[0, 5, 10, 15, 19]` (3 fourths + a third on top) | The definitive modal jazz sound |
| **Quintal** | stack 7s: `[0, 7, 14, 21]` | Vast, open, Copland, epic score |
| **Cluster** | `[0, 2, 4]` or `[0, 1, 3]` | Texture not harmony; horror, ambient, Debussy |
| **Slash chord** | any chord over a foreign bass, e.g. `F/G` = `[0,4,9]` over G | The cheapest way to add sophistication; see below |
| **Upper structure** | a triad from a foreign key stacked over a dominant | e.g. D major triad over C7 = C13#11 |

### Slash chords worth memorising (in C major)

| Written | Actual sound | Use |
|---|---|---|
| `C/E` | first-inversion C | Smooth bass line |
| `C/G` | second-inversion C | Suspended, pre-cadential |
| `F/G` | G11sus, "deferred dominant" | House, gospel, 80s pop — resolve to C |
| `Am/G`, `G7sus` family | pedal-point motion | Static bass, moving chords |
| `Bb/C` | C7sus with a b7 flavour | Funk, neo-soul |
| `D/C` | Clydian, C6/9#11 | Bright, floaty |
| `Ab/Bb` | Bb11sus | The 80s power ballad chord |

## Inversions and voicing

The same chord in different arrangements is a different musical object.

**Inversion** = which chord tone is in the bass.

| Inversion | Bass note | Feel |
|---|---|---|
| Root position | root | Stable, final, blunt |
| 1st inversion | 3rd | Light, moving, transitional |
| 2nd inversion | 5th | Unstable, suspended, needs to resolve |
| 3rd inversion (7th chords) | 7th | Falling, wants to descend a step |

**Voicing** = the actual octave placement of each note. Rules that matter:

1. **Spacing**: wide intervals at the bottom, narrow at the top. Mirror the
   harmonic series. A minor 3rd below C3 is mud; the same third at C5 is sweet.
2. **Low interval limits** — the lowest usable interval by register (see
   `07-voice-leading.md` for the full table): below E2 use octaves and fifths
   only; thirds are safe from about F2/G2 upward.
3. **Doubling**: doubling the root or fifth is safe; doubling the 3rd of a major
   chord makes it aggressive; doubling a 7th or an extension is usually wrong.
4. **Omission**: in a dense mix, drop the 5th first (it adds nothing), then the
   root (the bass has it). Keep the **3rd and 7th** — those two notes define the
   chord's identity and are called **guide tones**.

### Rootless voicings

Because the bass plays the root, the chord instrument does not have to.

| Chord | Rootless voicing (offsets from root) | Actual notes for Cm9 root C |
|---|---|---|
| `Cm9` | `[3, 7, 10, 14]` | Eb G Bb D |
| `Cm9` (alt) | `[10, 14, 15, 19]` | Bb D Eb G |
| `C13` | `[4, 9, 10, 14]` | E A Bb D |
| `Cmaj9` | `[4, 7, 11, 14]` | E G B D |
| `C7b9` | `[4, 10, 13, 21]` | E Bb Db A |

Rootless voicings are the sound of jazz piano, deep house chords, and liquid
drum'n'bass. They also **free the low end for the bass**, which is a mix
decision as much as a harmonic one.

### Drop voicings

Take a close-position 4-note chord and drop one voice down an octave.

| Name | Which voice drops | Result |
|---|---|---|
| Drop 2 | 2nd from top | Open, balanced — the default for guitar and strings |
| Drop 3 | 3rd from top | Wider, big-band |
| Drop 2+4 | 2nd and 4th from top | Very open, orchestral |

Example, Cmaj7 close `[60, 64, 67, 71]` → drop 2 → `[55, 60, 64, 71]`.

## Chords built from a scale (diatonic harmony)

Stack thirds on each degree of the scale. This is where progressions come from.

**Major scale (C):**

| Degree | Triad | 7th chord | Function |
|---|---|---|---|
| I | C | Cmaj7 | Tonic — home |
| ii | Dm | Dm7 | Subdominant — departure |
| iii | Em | Em7 | Tonic-ish, fragile |
| IV | F | Fmaj7 | Subdominant — the lift |
| V | G | G7 | Dominant — tension |
| vi | Am | Am7 | Tonic-ish, the sad relative |
| vii° | Bdim | Bm7b5 | Dominant function, rarely used as-is |

**Natural minor (A):**

| Degree | Triad | 7th chord | Function |
|---|---|---|---|
| i | Am | Am7 | Tonic |
| ii° | Bdim | Bm7b5 | Subdominant, unstable |
| bIII | C | Cmaj7 | The relative major — brightness |
| iv | Dm | Dm7 | Subdominant |
| v (or V) | Em (Em7) / **E7** | | Dominant — raise the 3rd for a real cadence |
| bVI | F | Fmaj7 | The big emotional chord in minor |
| bVII | G | G7 | Rock/modal cadence back to i |

**Harmonic minor (A) changes v→V and gives:** `i, ii°, bIII+, iv, V7, bVI, vii°7`.

## Chord symbol quick parse

```
[root][quality][extension][alterations]/[bass]
Cm7b5     → root C, minor, b7, flat 5
F#maj9    → root F#, major 7 + 9
Bb13#11   → root Bb, dominant 13 with #11
Ab/Bb     → Ab major triad over a Bb bass
Dsus4/A   → D sus4, 2nd inversion
```

Common shorthand: `Δ` = major 7, `−` = minor, `ø` = half-diminished,
`°` = diminished, `+` = augmented, `alt` = altered dominant.

## Choosing chords for a genre — quick map

| Genre | Default chord vocabulary |
|---|---|
| Techno / minimal | Often none. One drone, one stab, maybe a m7 |
| Big-room / hardstyle | Bare triads, i–bVI–bIII–bVII, minimal 7ths |
| Trance | Triads and add9/sus4; big, simple, uplifting |
| House / deep house | m7, m9, maj7, 7sus4, rootless voicings |
| Liquid D&B | m9, maj9, add9, ii–V colours, jazz influence |
| Lo-fi / chillhop | maj7, m9, 6/9, m11, borrowed chords, always 4+ notes |
| Trap / drill | Minor triads and m7; harmony is minimal, texture carries it |
| Neo-soul / R&B | m9, 13, altered dominants, slash chords, upper structures |
| Jazz | Everything above plus alterations and reharmonisation |
| Rock / metal | Power chords, triads, sus, occasional add9 |
| Cinematic | Triads with wide spacing, sus2, quartal, chromatic mediants |
