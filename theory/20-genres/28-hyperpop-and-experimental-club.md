# Hyperpop and Experimental Club

**Identity:** the internet's native pop. Maximalist, deliberately artificial,
built from extreme processing, and unconcerned with the conventions of "good"
production.

## Hyperpop

| Parameter | Value |
|---|---|
| Tempo | 130–170 (often 160) |
| Meter | 4/4 |
| Key | Major and minor, bright, with pop progressions |
| Length | 1:30–2:30 |
| Loudness | −7 to −5 LUFS (clipping is the aesthetic) |

### Characteristics

- **Extreme vocal processing**: hard autotune with a retune speed of 0, formant
  shifting, pitch-shifted stacks, doubled octaves, vocoders.
- **Distortion everywhere**: bitcrushing, clipping, saturation applied until
  elements break.
- **Maximalism**: 20 things happening; sudden switches; genre collisions inside
  one track.
- **Bright, plastic timbres**: supersaws, FM bells, detuned square leads, "toy"
  sounds, 8-bit textures.
- **Pop harmony**: the chord progressions are ordinary; the surface is not.
- **Abrupt structure**: sections change without transitions; a track can switch
  genre halfway.
- **Short**: made for short-form video and playlists.

### Drums
```
kick:   x - - - | - - x - | - - - x | - - - -
snare:  - - - - | x - - - | - - - - | x - - -
hat:    x x x x | x x x x | x x r r | x x x x
```
Trap-derived but faster and more distorted. Often the whole drum bus is clipped.

### Production moves
- Clip the master hard; the distortion is intentional.
- Pitch the entire mix up or down mid-track.
- Reverse a section.
- Cut to silence and back.
- Layer 5+ vocal takes at different octaves and pitches.
- Use "wrong" sounds — mismatched reverbs, obvious presets, sounds that clash.

## Experimental and deconstructed club

Umbrella for music that uses club signifiers without club function.

| Style | Feature |
|---|---|
| **Deconstructed club** | Club sounds without a danceable groove; texture and tension |
| **Ballroom / vogue** | 125–135, the "ha" crash on beat 5 of an 8-count, chants |
| **Jersey club** | 130–140, triplet kick pattern, chopped vocals, bed squeak |
| **Baltimore club** | 130, breakbeat + chopped vocals |
| **Footwork / juke** | 155–165, triplet 808s, obsessive vocal repetition |
| **Gqom** | 120–130, minimal, dark, broken 4/4 |
| **Shatta / dembow experimental** | 100–110, Caribbean, aggressive |
| **Hardgroove / bounce** | 130–150, percussive, tribal |
| **Digicore / glitchcore** | 140–170, hyperpop + emo rap |
| **Wave** | 140–150, melancholic, halftime, atmospheric |
| **Trance revival / hard dance** | 140–160, rave nostalgia, contemporary production |
| **Breakcore revival** | 160–200, chopped breaks + emotional melodies |

### Jersey club kick pattern
```
kick:   x - x x | - - x - | x - x x | - - x -     (the "triplet" 5-kick pattern)
```
Written as two groups: `x . x x . ` — a distinctive stuttering triplet feel over
4/4.

### Ballroom
```
kick:   x - - - | x - - - | x - - - | x - - -
crash:  - - - - | - - - - | - - - - | x - - -   (the "ha" on the & of 4 / beat 5)
```
The "ha" — a vocal crash sample — on the last beat of every 8-count is the
identity.

## Production notes

- **Break the rules deliberately.** Clipping, mono-incompatible width, harsh
  frequencies and mismatched reverbs are all legitimate here — but only if
  chosen.
- **Contrast is still king.** Maximalism only reads as maximal if something is
  minimal nearby.
- Reference the source genres accurately; these styles are built from recognisable
  club signifiers, and getting them wrong reads as ignorance rather than
  subversion.
- Short attention spans are designed for: change something every 4 bars.

## Signature techniques

- **Break rules deliberately.** Clipping, mono-incompatible width and harsh
  frequencies are legitimate here only when chosen.
- **Hard autotune at zero retune speed** — the stepped glide between notes is the
  instrument.
- **Vocal stacks in several octaves**, formant-shifted apart.
- **Abrupt structure.** Cut between sections with no transition; switch genre
  mid-track; reverse a bar; pitch the whole mix.
- **Maximalism needs a minimal neighbour** — it only reads as maximal by
  contrast.
- **A real pop hook underneath.** The best of this music is a strong topline with
  the surface destroyed.
- **Keep it short**: 1:30–2:30, with something changing every 4 bars.

## Hazards

- Chaos without a hook. The best hyperpop has a genuinely strong pop melody
  under the noise.
- Distortion applied uniformly, so nothing stands out.
- No dynamic range at all — even here, contrast is what makes the loud parts
  loud.
- Treating "experimental" as a substitute for having an idea.
