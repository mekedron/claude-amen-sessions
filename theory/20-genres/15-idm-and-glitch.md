# IDM, Glitch and Experimental Electronic

**Identity:** electronic music that treats the machine's errors as material.
Rhythmically complex, harmonically unusual, and made for listening rather than
dancing.

## Numbers

| Parameter | Value |
|---|---|
| Tempo | 60–200; often changes mid-track |
| Meter | 4/4, 7/8, 5/4, polymetric layers, or no meter |
| Key | Modal, chromatic, microtonal, or deliberately ambiguous |
| Loudness | −14 to −9 LUFS; dynamics preserved |

## Rhythm — the core of the genre

| Technique | Description |
|---|---|
| **Micro-editing** | Every drum hit individually placed, pitched and processed |
| **Polymeter** | Layers with cycle lengths of 5, 7, 9, 11 steps over a 16-step bar |
| **Polyrhythm** | 3:4, 5:4, 7:8 simultaneously |
| **Euclidean rhythms** | E(k,n) patterns, rotated |
| **Stutter / retrigger** | A single hit repeated at accelerating rates |
| **Glitch** | Buffer errors, clicks, digital artefacts used as percussion |
| **Time-stretching artefacts** | Granular smearing as texture |
| **Tempo modulation** | Gradual or abrupt tempo changes |
| **Beat displacement** | The whole pattern shifted by a 16th or 32nd |
| **Probability** | Each step has a chance of firing, so the loop never repeats |
| **Breakcore chopping** | Amen breaks edited into unrecognisable fragments |

**A useful method:** write a straightforward beat, then destroy it — shift
individual hits off-grid, replace some with silence, stutter one, pitch another
down two octaves, reverse a third. The skeleton keeps it coherent; the damage
makes it IDM.

## Harmony and melody

- Modal and gentle (Aphex Twin's ambient works, Boards of Canada) or
  atonal and abrasive (Autechre's later work).
- **Detuned/microtonal** melodies — deliberately slightly out of tune, which
  reads as nostalgic and uncanny.
- Simple, beautiful melodies against complex rhythms is the classic contrast.
- Chords: maj7, m9, quartal, cluster, or bare fifths.
- Slow harmonic rhythm — often one chord for 16 bars while the drums riot.

## Sound design

| Technique | Use |
|---|---|
| **Granular** | Clouds, freezes, textures |
| **FM with inharmonic ratios** | Metallic, bell-like, alien |
| **Physical modelling** | Impossible instruments |
| **Resampling chains** | Process, bounce, process again, 5+ times |
| **Convolution with non-room IRs** | Convolve a drum with a voice, a room with a synth |
| **Bit reduction / SRC** | Digital grit |
| **Spectral freezing and morphing** | Sustained impossible timbres |
| **Feedback networks** | Self-generating material |
| **Broken/circuit-bent instruments** | Unpredictable behaviour |
| **Vintage sampler artefacts** | 12-bit converters, aliasing |

## Subgenres

| Style | Feature |
|---|---|
| **IDM (classic)** | Warp Records lineage; melodic, complex rhythms |
| **Braindance** | Playful, acid-influenced, retro-futurist |
| **Glitch** | Digital errors as primary material |
| **Clicks & cuts / microsound** | Minimal, tiny sounds, near-silence |
| **Breakcore** | Extreme break editing, fast, chaotic, 170–250 |
| **Drill'n'bass** | Hyper-edited D&B, 1990s |
| **Wonky / hip-hop IDM** | Off-kilter, drunken swing, LA beat scene |
| **Deconstructed club** | Club signifiers dismantled; textural |
| **Ambient IDM** | Melodic, gentle, complex |
| **Noise / harsh noise** | Pure texture, extreme |
| **Musique concrète** | Recorded sound as composition material |
| **Electroacoustic** | Academic tradition; spatialisation, spectral |
| **Modular / generative** | Rule-based systems making the music |
| **Chiptune / bytebeat** | Deliberate hardware constraints |

## Arrangement

Through-composed rather than loop-based. Techniques:

- **Continuous transformation**: the pattern at bar 64 is a mutation of the one
  at bar 1, and every bar in between is a step.
- **Layer independence**: elements enter and leave on their own cycles, not on
  a shared phrase boundary.
- **Sudden juxtaposition**: a hard cut to entirely different material.
- **A single beautiful moment** placed late, earned by everything before it.
- **No obligation to return.** IDM tracks often end somewhere entirely unrelated
  to where they began.

## Production notes

- **Preserve dynamics.** Detail is the aesthetic; limiting flattens it.
- **Stereo detail** matters — individual percussion hits panned precisely.
- Frequency-wise, this music is often deliberately unbalanced. That is allowed;
  just make it a choice.
- Automate everything. Every parameter of every element, constantly.
- Randomness with constraints beats pure randomness: choose from a scale, from
  a set of durations, from a probability table.

## Generative approaches

Useful rule systems for programmatic composition:

| System | Description |
|---|---|
| **Markov chains** | Next note depends on the previous 1–2 notes; train on a corpus |
| **Cellular automata** | Rule 110 etc., mapped to a pitch/rhythm grid |
| **L-systems** | Recursive rewriting; good for melodic development |
| **Euclidean generators** | E(k,n) with per-layer rotation |
| **Probability grids** | Each step has a firing probability that itself evolves |
| **Constraint satisfaction** | "Must be in scale, must not repeat within 3 notes" |
| **Chaotic maps** | Logistic map, Lorenz attractor mapped to parameters |
| **Physical simulation** | Bouncing balls, particle systems, driving triggers |

**HAZARD:** pure randomness sounds random, not interesting. Every good
generative system has (1) a constrained pitch set, (2) a rhythmic grid or
strong metrical bias, (3) repetition somewhere, and (4) a human curating the
seeds and keeping only the good outputs.

## Hazards

- Complexity without a centre — the listener needs one stable thing to hold on to.
- Randomness mistaken for composition.
- All texture and no event.
- Making it too clean; the grit is the point.
- Making it *only* difficult; the best IDM is also beautiful.
