# Ambient, Drone and Sound Design Music

**Identity:** music where timbre and time replace melody and rhythm. Brian Eno's
definition still holds: "as ignorable as it is interesting."

## Numbers

| Parameter | Value |
|---|---|
| Tempo | None, or 50–90 BPM if pulsed |
| Meter | Often free; when metered, 4/4 or slow compound |
| Key | Modal, static; often one chord for the whole piece |
| Length | 4–20 minutes, or hours |
| Loudness | −20 to −14 LUFS; dynamic range preserved |

## Construction

Ambient is built from **layers with different cycle lengths** so that the
combination never exactly repeats.

| Layer | Function | Typical cycle |
|---|---|---|
| **Drone** | The harmonic foundation | Continuous |
| **Pad** | Slow chordal movement | 30 s–4 min |
| **Texture** | Noise, field recording, granular cloud | Continuous, evolving |
| **Motif** | A short melodic fragment | Every 20–60 s, irregular |
| **Event** | A single distinctive sound | Every 1–3 min |
| **Pulse** (optional) | Slow rhythmic element | Regular |

Give each layer a loop length that is coprime with the others (e.g. 17 s, 23 s,
31 s) and the piece will not repeat for a very long time.

## Harmony

- **One chord** is a legitimate and common choice. Add and remove notes from it
  over minutes.
- Modal: Lydian (bright, floating), Aeolian (melancholic), Dorian (neutral),
  Phrygian (dark).
- **Quartal voicings** (stacked fourths) avoid the major/minor commitment.
- Slow chord changes: one every 16–64 bars, or one every 30–90 seconds.
- Chromatic mediants for gentle harmonic surprise.
- **Just intonation and microtonal drift** are more available here than anywhere
  else — sustained tones tuned a few cents apart beat beautifully.

## Techniques

| Technique | Description |
|---|---|
| **Granular synthesis** | Cloud of tiny grains from a source; freeze, stretch, blur |
| **Convolution** | Convolve a sound with an unusual impulse response |
| **Long reverb** | 10–60 s decay; the reverb becomes the instrument |
| **Shimmer reverb** | Reverb with +12 (and −12) pitch-shifted feedback |
| **Tape loops** | Repeating with accumulating degradation |
| **Feedback systems** | Delay lines feeding each other |
| **Field recording** | Real spaces as harmonic and rhythmic material |
| **Generative rules** | Probability-driven note choice within a scale |
| **Spectral processing** | Freeze, blur, or filter the FFT spectrum |
| **Slow modulation** | LFOs at 0.01–0.1 Hz on everything |
| **Reverse everything** | Reversed piano, reversed cymbals, reversed reverb |
| **Extreme time-stretch** | Stretch a 3-second sample to 5 minutes |

## Subgenres

| Style | Feature |
|---|---|
| **Ambient (Eno-style)** | Melodic fragments, generative, gentle |
| **Dark ambient** | Low drones, dissonance, unease, industrial texture |
| **Drone** | One sustained sound, minimal change, 20+ min |
| **Space ambient / berlin school** | Sequencers, analogue synths, cosmic |
| **Ambient techno** | Beats plus atmosphere, 120–130 |
| **Lowercase** | Extremely quiet, microscopic sounds |
| **Isolationism** | Cold, empty, post-industrial |
| **New age** | Consonant, harp/piano, wellness-oriented |
| **Neoclassical / modern classical ambient** | Piano and strings, tape treated |
| **Kosmische / krautrock ambient** | Motorik pulse, analogue |
| **Ambient dub** | Dub delay techniques, bass, space |
| **Hauntology** | Degraded tape, nostalgic, memory-as-decay |
| **Healing / functional** | Binaural, sleep, focus — designed for a use |

## Arrangement over long durations

Structural thinking for a 10-minute piece:

```
0:00-1:30   Establish one element. Let it exist alone.
1:30-3:30   Introduce a second layer, very gradually (30 s fade-in).
3:30-5:30   Harmonic shift. The first real "event".
5:30-7:30   Density peak: 4–5 layers.
7:30-9:00   Subtraction. Return to something like the opening.
9:00-10:00  Decay to silence, or a single held tone.
```

**Fade times are the primary tool.** A 60-second fade-in is normal. Nothing
should arrive suddenly unless the suddenness is the event.

## Sound design palette

Analogue pads, bowed strings and cymbals, prepared piano, sine drones, filtered
noise, field recordings (rain, wind, rooms, machines, cities), tape hiss, bells,
resonant metals, processed voice, guitar through infinite reverb, modular
generative patches.

## Production notes

- **Dynamic range is the point.** Do not compress or limit heavily. Peaks at
  −6 dBFS with an integrated loudness of −18 LUFS is normal.
- **High-pass carefully.** Low-frequency drones are the foundation; but remove
  actual rumble below 25 Hz.
- **Stereo width is available** here in a way it is not in club music — wide,
  decorrelated, immersive.
- Watch for **frequency build-up** in sustained layers: with everything held,
  masking is constant. Give each layer its own band.
- **Silence is allowed.** Real silence, several seconds long.
- Avoid obvious loop points — vary tails and use long crossfades.

## Hazards

- Static in the wrong way: no change over 10 minutes is boredom, not ambience.
  Something must evolve, even imperceptibly.
- Too much reverb on everything: the whole piece turns to fog with no foreground.
- Building it like a dance track (intro/build/drop) — the wrong grammar.
- Compressing it to a modern loudness target — destroys the genre.
- Loops that are audibly loops.
