# MIDI, Note Name and Frequency Table

`freq = 440 * 2 ** ((midi - 69) / 12)`  ·  `midi = 69 + 12 * log2(freq / 440)`

Octave numbering is scientific pitch notation: **C4 = MIDI 60 = middle C**.
Pitch class = `midi % 12`, octave = `midi // 12 - 1`.

Wavelength assumes a speed of sound of 343 m/s (20 °C, dry air) — useful for
room acoustics and for knowing which frequencies your room cannot reproduce.
