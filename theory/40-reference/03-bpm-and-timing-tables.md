# BPM, Timing and Tempo Tables

Everything time-based in a mix should come from these numbers. A delay set to
"about 300 ms" is noise; a delay set to a dotted 8th is a part.

## The formulas

```
seconds_per_beat = 60 / BPM
ms_per_beat      = 60000 / BPM
ms_per_bar (4/4) = 240000 / BPM
ms_per_16th      = 15000 / BPM
hz_for_note      = BPM / 60 / beats_per_cycle
bars_for_seconds = seconds * BPM / 240        (4/4)
seconds_for_bars = bars * 240 / BPM           (4/4)
```

Note-length multipliers (in beats): whole = 4, half = 2, quarter = 1,
eighth = 0.5, sixteenth = 0.25. **Dotted** = ×1.5. **Triplet** = ×2/3.

## Practical settings derived from tempo

| Use | Note value | Why |
|---|---|---|
| Sidechain release | 1/16 or 1/8 | Recovers just before the next kick |
| Slapback delay | 1/16 or free 80–120 ms | Single close echo |
| Rhythmic delay | 1/8 dotted | The classic; syncopates against 4/4 |
| Wide delay | 1/4 or 1/2, ping-pong | Space without clutter |
| Reverb pre-delay | 1/64 to 1/32 (10–40 ms) | Keeps transients clear |
| Reverb decay (rhythmic material) | ≤ 1 bar | Longer washes out the groove |
| Tremolo | 1/8 or 1/16 | Rhythmic pulsing |
| Wobble LFO | 1/4, 1/8, 1/8T, 1/16, 1/32 | Dubstep; change per bar |
| Filter sweep (build) | 4–16 bars | Section-scale energy |
| Pad filter LFO | 2–8 bars (0.03–0.25 Hz) | Slow evolution |
| Autopan | 1 or 2 bars | Movement without distraction |
| Compressor attack (drums) | 10–30 ms | Lets the transient through |
| Compressor release (bus) | ~1 beat | Musical pumping |

## Tempo relationships worth knowing

| Relationship | Example | Use |
|---|---|---|
| ×2 / ÷2 | 85 ↔ 170 | Trap ↔ drum & bass; halftime/doubletime |
| ×1.5 | 100 → 150 | Triplet feel becomes straight |
| ÷1.5 | 174 → 116 | D&B triplets read as house |
| ×4/3 | 105 → 140 | Common remix relationship |
| Same grid, halftime feel | 174 felt as 87 | D&B breakdowns |
| Same grid, doubletime feel | 70 felt as 140 | Trap hats over a slow beat |
